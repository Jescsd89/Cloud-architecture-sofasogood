# Cloud-architecture-sofasogood
Cloud Architecture for Sofa-so-good: A Personal Data Engineering Journey
By Jesus Medina

This article details the process of designing and implementing a cloud-based data architecture for Sofa-so-good, a medium-sized furniture retail company. As part of a personal data science project, I designed a scalable and reliable cloud infrastructure to streamline the company's data access, analytics, and reporting capabilities. This report outlines the design decisions, technical components, and business applications of the final architecture.
